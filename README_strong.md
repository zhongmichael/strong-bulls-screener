# 多周期强势股选股器（Strong Bulls Screener）

基于 A 股日/周/月三周期均线结构的多周期强势股动态股池选股器，全市场约 4600 只覆盖，支持历史日期回看。

## 核心逻辑

**强势股池 = 周月持续强势（规则D）**
- 周线近 10 周 ≥ 7 周收盘站上周 MA5（核心条件）
- 且（月线近 12 月 ≥ 6 月站上月 MA5 **或** 三周期强度 ≥ 50）
- "日周月全站上 MA5" **不作为强势依据**（只是当日勉强站上三线，非强势股）

**配套功能**
- 周/月连续站上排序（周线连续 → 月线连续 → 强度 三要素）
- 回踩 10 / 20 日线附近（强势回踩评分：前期涨幅+均线多头+缩量+K线止跌+收回速度+周线配合）
- 板块分布统计（行业/概念双维度，点击数量弹个股明细）
- 上涨逻辑自动概括（20日涨幅/当日异动/站上年线/均线多头/三线共振）

## 文件说明

| 文件 | 说明 |
|---|---|
| `strong_screener.html` | 选股器网页（入口，需 `strong_data.js` + `echarts.min.js`） |
| `compute_strong.py` | 全市场强势/回踩/强度计算（多进程，约 10 秒） |
| `update_strong.py` | **一键更新脚本**：抓K线 → 重算 → 打包 → 同步部署目录 |
| `fetch_kline.py` | 日K线抓取（腾讯自选股接口，并发） |
| `fetch_stocks.py` | 全市场股票列表抓取 |
| `fetch_blocks.py` | 个股所属板块抓取（东方财富接口，行业+概念） |
| `echarts.min.js` | 图表库（第三方） |

## 数据文件（不入库，运行时生成）

- `data/kline/*.json` — 全市场日K线（腾讯前复权）
- `data/out/strong_2026.json` — 逐日强势/回踩计算结果
- `strong_data.js` — 网页数据包（由 update_strong.py 生成）

## 使用

```bash
# 1. 首次准备数据
python3 fetch_stocks.py        # 股票列表
python3 fetch_kline.py         # 全市场K线（约3-4分钟）
python3 fetch_blocks.py        # 板块信息
python3 compute_strong.py      # 计算强势数据

# 2. 生成网页数据包
python3 update_strong.py       # 一键更新（含抓取+重算+打包）

# 3. 打开网页
# 直接用浏览器打开 strong_screener.html 即可（file:// 协议）
```

交易日收盘后运行 `python3 update_strong.py` 即可更新到最新数据。
